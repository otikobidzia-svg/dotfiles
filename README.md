dotfiles

My personal dotfiles.

Requirements

Make sure the following are installed before setting these up:

Hyprland — Wayland compositor / window manager
kitty — terminal emulator
yambar — status bar
fastfetch — system info tool
Installation
git clone https://github.com/otikobidzia-svg/dotfiles.git ~/dotfiles
cd ~/dotfiles
# symlink or copy configs into place, e.g.:
# ln -s ~/dotfiles/hypr ~/.config/hypr
# ln -s ~/dotfiles/kitty ~/.config/kitty
# ln -s ~/dotfiles/yambar ~/.config/yambar

Feel free to use and adapt anything here for your own setup.
